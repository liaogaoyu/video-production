剪映分镜草稿包（兼容性试用）

1. 把整个 ZIP 解压到本机，不要直接在压缩包内运行。
2. 先退出剪映，查看剪映“设置 → 草稿位置”。
3. Windows：双击“导入剪映-Windows.cmd”，输入草稿位置或回车使用默认值。
   Mac：终端输入 bash 后加空格，把“导入剪映-Mac.command”拖进终端，回车执行。
   Mac 脚本使用系统自带 Perl/JSON::PP，不需要 Python、Node 或 FFmpeg。
4. 重新打开剪映，在草稿列表查找项目名称。脚本只新建独立目录，不覆盖已有草稿。

时间线：按集数 → 镜头编号 → 分镜 ID 排序；每个分镜取最新成功并已下载的视频。
使用视频的实际时长，保留原声；未生成的视频列在 timeline.json 的 missing 清单中。
重复导入同一个包会提示已存在；不要随意移动已导入的草稿或 media 子目录。

兼容性说明：
这是剪映专业版的本地草稿格式，不是剪映官方导入 API。不同版本的草稿格式可能变化。
当前完成草稿结构、视频时间线和 Mac 路径安装验证；Windows 脚本及 Windows/Mac 剪映内打开与播放尚未实机验收。
如剪映提示草稿损坏或不显示，请保留原视频，不要覆盖其他草稿，并反馈剪映版本号。
即使草稿暂不兼容，也可在分镜页面使用“按顺序导出视频”下载原视频。
